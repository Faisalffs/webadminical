1. IKHTISAR SISTEM (SYSTEM OVERVIEW)
--------------------------------------------------------------------------------
Fayseri adalah platform dashboard terpadu berbasis web yang dirancang khusus untuk
monitoring dan otomasi greenhouse pertanian pintar (fokus saat ini: Kebun Cabai).
Sistem ini memadukan kemudahan penggunaan Vanilla JS/HTML/CSS dengan keamanan dan
kecepatan database cloud Supabase untuk menyajikan metrik pertanian secara presisi,
real-time, dan responsif baik di desktop maupun perangkat mobile.

2. ARSITEKTUR TEKNOLOGI (TECH STACK)
--------------------------------------------------------------------------------
- Frontend CORE: HTML5 (Struktur Semantik), CSS3 (Desain Sistem Premium), Vanilla JS (ES6+)
- Visualisasi Data: Chart.js (Grafik Suhu, Kelembaban, dan Pertumbuhan)
- Penyimpanan Awan & Autentikasi: Supabase JS v2 Client SDK
- Integrasi API Cuaca: Open-Meteo Weather API (Lokasi: Kebon 9, Sungai Gelam, Jambi)
- Paket Ikonografi: FontAwesome v6.4.0 (Pro & Solid)
- Tipografi: Inter, Montserrat, & Poppins (diambil via Google Fonts)

3. STRUKTUR DATABASE SUPABASE (DATABASE SCHEMA)
--------------------------------------------------------------------------------
Sistem menggunakan pola penyimpanan JSON Cloud-First (Key-Value Document Pattern)
pada tabel tunggal `fayseri_storage` untuk fleksibilitas modular tanpa overhead join
relasional yang rumit:

Tabel: `fayseri_storage`
├── user_id     : UUID (Foreign Key ke auth.users Supabase) - Kunci Utama Partisi
├── key_name     : TEXT (Nama modul, unik untuk setiap user_id)
├── value_data   : JSON (Data payload berstruktur dokumen)
└── updated_at   : TIMESTAMP WITH TIME ZONE (Waktu update terakhir)

Daftar Dokumen/Key yang Tersimpan (`key_name`):
1. `fayseri_tanaman`            : Menyimpan daftar tanaman, varietas, umur, dan fase.
2. `fayseri_pekerjas`           : Menyimpan manajemen pekerja lapangan.
3. `fayseri_watering_schedules` : Menyimpan konfigurasi jadwal tugas penyiraman/pemupukan.
4. `fayseri_kas`                 : Menyimpan catatan kas masuk dan kas keluar.
5. `fayseri_profil`             : Menyimpan data personal admin, nama lengkap, & NAMA PANGGILAN.
6. `fayseri_konfig`             : Menyimpan nama lahan, zona waktu, unit suhu, dan tema.
7. `fayseri_theme`              : Menyimpan konfigurasi tema aktif (faesa, light, dark).
8. `fayseri_produk_siap_jual`   : Menyimpan katalog produk siap jual untuk toko online eksternal.

4. DESAIN SISTEM & PALET WARNA (THEMING SYSTEM)
--------------------------------------------------------------------------------
Aplikasi memiliki 3 tema utama yang diatur secara reaktif menggunakan atribut `data-theme`
pada elemen root `<html>`:

A. Tema "Faesa" (Default Premium Indigo-Blue)
   - Background Utama   : #f8fafc (Sangat bersih) dengan teknologi Aurora Animated Background di belakang konten
   - Warna Utama       : #6366F1 (Indigo Modern)
   - Topbar Header      : #0d6efd (Bootstrap 5 Blue) dengan transparansi & kaca glassmorphism
   - Background Sidebar : Gradasi ganda (arang tua ke hijau hutan) dengan pola matriks mikro-titik dan bola-bola cahaya asinkron (Greenhouse Green & Indigo Blue) yang melayang lambat secara dinamis (.sidebar-bg-glows)
   - Pembatas Sidebar   : Subtle dark border (rgba(0,0,0,0.25)) untuk mengeliminasi garis putih vertikal
B. Tema "Light" (Putih Bersih)
   - Kontras tinggi dengan border abu-abu lembut (#cbd5e1)
C. Tema "Dark" (Gelap Premium)
   - Background Utama   : #0f172a (Slate 900)
   - Background Kartu   : #1e293b (Slate 800)
   - Warna Utama       : #818CF8 (Light Indigo)

5. LAYOUT RESPONSIVE & OPTIMASI DESAIN TOMBOL KOMPAK
--------------------------------------------------------------------------------
A. Penghapusan Tombol Sinkronkan Data:
   - Tombol `#btnRefreshDashboard` ("Sinkronkan Data") dihapus dari baris header menu Dashboard 
     untuk merapikan antarmuka utama. Inisialisasi JS telah diproteksi secara asinkron (`if (btnSync)`).

B. Tombol Ukuran Kompak (btn-sm) Desktop & Mobile:
   - Kelas `.btn-sm` dideklarasikan secara global untuk menyusutkan tombol aksi penting dari ukuran default 
     menjadi lebih ramping (padding `5px 10px !important`, font-size `11.5px !important`, tinggi/lebar otomatis).
   - Diaplikasikan pada tombol utama:
     - **Konfigurasi Sistem:** Tombol "Simpan" (`btnSimpanKonfig`) & "Reset" (`btnResetKonfig`).
     - **Profil Saya:** Tombol "Edit Profil" (`btnEditProfil`), "Batal" (`btnBatalEditProfil`), & "Simpan Perubahan" (`btnSimpanProfil`).
     - **Buku Panduan:** Tombol "Tambah Panduan Baru" (`btnTambahPanduan`) & "Refresh" (`btnRefreshPanduan`).
     - **Produk Siap Jual:** Tombol "Tambah Produk Baru" (`btnTambahProduk`) & "Refresh" (`btnRefreshProduk`).

C. Ultra-Shrink Mobile (max-width: 480px):
   - Pada ponsel kecil, tombol `.btn-sm` dan ID tombol utama di atas menyusut lebih kecil lagi (font-size `10px !important`, 
     padding `4px 8px !important`, gap `3px !important`) agar menghemat ruang.
   - Ditambahkan pembatas **`flex: none !important;`** untuk membatalkan peregangan tombol secara horizontal 
     agar tombol tidak melebar memenuhi lebar layar ponsel.

D. Widget Topbar Responsif:
   - Pada lebar layar <= 768px, jam digital (.topbar-clock) disembunyikan.
   - Widget cuaca (.env-widget) hanya menampilkan metrik **SUHU** saja demi menjaga estetika minimalis.

6. INTEGRASI FITUR & RECOVERY DATA (RACE-CONDITION FIX)
--------------------------------------------------------------------------------
A. Solusi Race-Condition Sidebar & UI:
   - Pada modul `Storage.syncFromDatabase()`, sistem mengabaikan penimpaan preferensi antarmuka lokal 
     (`fayseri_sidebar`, `fayseri_theme`, `fayseri_page`) dari database cloud jika nilai tersebut sudah aktif 
     di `localStorage`. Ini mencegah sidebar atau menu "melompat" kembali terbuka setelah ditutup secara cepat saat dimuat.

B. Persistensi Sesi & Status Sidebar Setelah Refresh:
   - **Persistensi Sesi Login Permanen:** Mengeliminasi pemanggilan `localStorage.clear()` asinkron pada inisialisasi / logout, menggantinya dengan penghapusan terarah (*targeted*) khusus tabel data pertanian saja. Ini mencegah terhapusnya kunci otentikasi Supabase `'fayseri-admin-session'` secara tidak sengaja, sehingga admin tidak perlu login ulang saat me-refresh browser atau membuka kembali web di hari berikutnya.
   - **Persistensi Sidebar:** Status sidebar diselamatkan secara aman saat logout dan dipulihkan penuh via `restoreSidebarState()` pasca otentikasi selesai mendeteksi sesi masuk.

C. Welcome Banner Global (3 Jadwal Terdekat):
   - Logic di `renderWelcomeBannerSchedule()` memetakan seluruh jadwal tugas aktif,
     menghitung sisa hari terdekat ke pemicu terdekat secara dinamis.
   - Mengambil 3 jadwal dengan jarak terpendek (0 = Hari Ini, 1 = Besok, n = Nama Hari).
   - Menampilkan icon spesifik aktivitas (Watering, Fertilizing, Spraying).

D. Aurora Animated Background (Animasi Latar Belakang Dashboard):
   - Menerapkan kontainer `.dashboard-bg-aurora` di belakang area utama dengan tiga bola pendaran cahaya (Indigo, Emerald Green, dan Sky Blue).
   - Bola-bola cahaya ini mengambang dan bergerak lambat secara asinkron menggunakan CSS @keyframes untuk menciptakan kedalaman visual modern dan mewah di latar belakang.
   - Otomatis dinonaktifkan di mode Light untuk menjaga kesederhanaan visual bersih.
